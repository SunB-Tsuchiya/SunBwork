# SunBWork リーダーマニュアル

---

## リーダーの役割

リーダーは、所属部署・チームのメンバー管理、日報の確認、作業量の分析を担います。
メンバーが適切な環境で働けるよう、チーム構成の整備や権限の付与を行うことも重要な業務です。

---

## 画面の見方

ログイン後、上部に以下のタブメニューが表示されます。
※表示されるタブはリーダー権限の設定によって異なります。

| タブ | 表示条件 | 内容 |
|------|----------|------|
| **ユーザー管理** | 部署リーダーのみ | 部署内ユーザーの登録・編集 |
| **チーム管理** | 全リーダー | チーム・ユニットの構成管理 |
| **クライアント管理** | 権限あり | 取引先の登録・編集 |
| **日報管理** | 権限あり | 部署内の日報を一覧・確認 |
| **作業量分析** | 権限あり | メンバーの作業量・負荷を分析 |
| **作業項目設定** | 権限あり | 作業種別・サイズ・ステージの設定 |
| **勤務時間管理** | 権限あり | 部署の勤務記録の確認・管理 |
| **派遣管理** | 権限あり | 派遣・業務委託メンバーの情報管理 |
| **Leader権限管理** | 全リーダー | 他リーダーへの権限付与・変更 |

---

## 基本的な使い方の流れ

```
チームとメンバーを整える（チーム管理・ユーザー管理）
        ↓
メンバーの日報を確認する（日報管理）
        ↓
メンバーの作業量・負荷を分析する（作業量分析）
        ↓
必要に応じてフィードバック・指示を行う
```

---

## 1. ユーザー管理（部署リーダーのみ）

**「ユーザー管理」タブ**では、自部署に所属するメンバーの情報を管理できます。

### できること

- メンバーの新規登録・情報編集
- 所属部署・チーム・担当の変更
- 役職・雇用形態の設定
- CSV でまとめてユーザー登録

### 雇用形態の種類

| 雇用形態 | 区分 |
|---------|------|
| 正社員・契約社員 | 日報提出が原則必須 |
| 派遣・業務委託 | 日報提出は任意（設定で変更可） |

---

## 2. チーム管理

**「チーム管理」タブ**では、部署内のチーム・ユニット構成を管理できます。

### チームの種類

| 種類 | 内容 |
|------|------|
| 部門チーム | 部署全体を束ねるチーム |
| ユニット | 部門内の小グループ |

### できること

- チーム・ユニットの新規作成・編集
- メンバーの追加・削除
- サブリーダーの設定（担当チームのみ管理権限を持つ）

---

## 3. 日報管理

**「日報管理」タブ**では、部署内の全メンバーの日報を一覧で確認できます。

### できること

- 日報の一覧・絞り込み（ユーザー別・日付別）
- 日報の詳細表示
  - 本文（作業の記録）
  - **その日の予定表タイムライン（カレンダーの予定が自動で反映されています）**
  - 勤務情報バー（始業・終業・休憩）
- コメントの追加（フィードバック・指示）

> **ポイント：** 日報を開くと、その日にメンバーが予定表に登録していたスケジュール（作業予定・イベント）が自動でタイムライン表示されます。文章の記録と予定表の記録を同時に把握できます。

---

## 4. 作業量分析

**「作業量分析」タブ**では、メンバーごとの作業量・負荷をスコアで可視化します。

### 分析の見方

| 指標 | 内容 |
|------|------|
| 総合ポイント（0〜600） | 6カテゴリの合計スコア |
| パーセンタイル | 同職種内での相対位置 |
| 偏差値（参考） | 全社を母集団とした分布上の位置 |

### 6つのカテゴリ

1. ステージ（作業の難易度・フェーズ）
2. サイズ（作業量の大きさ）
3. 種別（作業の種類）
4. 難易度（ページ単位の難易度係数）
5. イベント（会議・外出などの時間）
6. 残業（通常残業・超過残業）

### できること

- 部署全体・チーム別の一覧表示
- 職種別ランキング表示
- 個人の詳細分析（期間指定）

> **活用例：** 特定のメンバーの負荷が高い場合は、ジョブの再分配やフォローを検討してください。

---

## 5. 勤務時間管理

**「勤務時間管理」タブ**では、部署内の勤務記録（始業・終業・休憩）を確認・管理できます。

---

## 6. 派遣管理

**「派遣管理」タブ**では、派遣・業務委託メンバーの詳細情報（派遣会社・契約期間など）を管理できます。

---

## 7. Leader 権限管理

**「Leader権限管理」タブ**では、同じリーダーロールを持つメンバーの権限を管理できます。

### 設定できる権限フラグ

| フラグ | 内容 |
|--------|------|
| ユーザー管理 | 部署ユーザーの登録・編集 |
| クライアント管理 | 取引先の管理 |
| 日報管理 | 部署の日報確認・コメント |
| 作業量分析 | 作業量スコアの閲覧 |
| 作業項目設定 | 作業種別・サイズなどの編集 |
| 勤務時間管理 | 勤務記録の閲覧・編集 |
| 派遣管理 | 派遣・業務委託情報の管理 |

## よくある質問

**Q. タブが表示されない**
→ 権限フラグが付与されていない可能性があります。管理者またはリーダー権限を持つ上位リーダーに確認してください。

**Q. 日報のタイムラインが空欄のメンバーがいる**
→ そのメンバーが予定表（カレンダー）にスケジュールを登録していない状態です。日報の文章だけでは記録が蓄積されないため、予定表も使うよう指導してください。

**Q. 作業量分析に数値が出ない**
→ 集計期間内に完了したジョブ・日報の記録が必要です。まだデータが少ない場合は時間をおいて確認してください。
