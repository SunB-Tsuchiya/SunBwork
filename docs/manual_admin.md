# SunBWork 管理者マニュアル（Admin向け）

---

## Adminの役割

Adminは、会社・部署・ユーザーの全体を管理する権限を持ちます。
SuperAdminから権限を委譲された代表Admin（筆頭管理者）と、権限フラグで制限された一般Adminの2種類があります。

---

## 画面の見方

ログイン後、上部に以下のタブメニューが表示されます。
※表示されるタブはAdmin権限フラグの設定によって異なります。

| タブ | 表示条件 | 内容 |
|------|----------|------|
| **会社管理** | 権限あり | 会社情報の編集 |
| **ユーザー管理** | 権限あり | 全ユーザーの登録・編集・削除 |
| **部署管理** | 権限あり | 部署・チーム構成の管理 |
| **日報管理** | 権限あり | 全社の日報を一覧・確認 |
| **クライアント管理** | 権限あり | 取引先の登録・編集 |
| **作業量分析** | 権限あり | 全社・部署・チームの作業量分析 |
| **勤務形態設定** | 権限あり | 出勤・在宅・夜勤などのシフト定義 |
| **勤務時間管理** | 権限あり | 全社の勤務記録の確認・管理 |
| **Admin権限管理** | 代表Adminのみ | 他Adminへの権限フラグ付与・変更 |
| **Leader権限管理** | 全Admin | Leaderへの権限フラグ付与・変更 |

---

## 基本的な使い方の流れ

```
会社情報を整える（会社管理）
        ↓
部署・チームを構成する（部署管理）
        ↓
ユーザーを登録・編集する（ユーザー管理）
        ↓
各Leaderに権限を付与する（Leader権限管理）
        ↓
運用状況を日報・作業量で確認する
```

---

## 1. 会社管理

**「会社管理」タブ**では、自社の基本情報を管理できます。

### できること
- 会社名・所在地・連絡先などの編集
- APP_NAMEに表示される会社名の変更（ブラウザタブに反映）

---

## 2. ユーザー管理

**「ユーザー管理」タブ**では、全社のユーザーを一元管理できます。

### できること
- ユーザーの新規登録・情報編集・削除
- ロール（役割）の割り当て
- 所属部署・担当・雇用形態の設定
- CSV でまとめてユーザー登録

### ロールの種類

| ロール | 色 | 概要 |
|--------|-----|------|
| SuperAdmin | 黄 | システム全体の最高権限者 |
| Admin | 赤 | 会社単位の管理者 |
| Leader | オレンジ | 部署・チームのリーダー |
| Coordinator | 緑 | 案件・ジョブの進行管理担当者 |
| User | 青 | 一般作業ユーザー |

### 雇用形態

| 雇用形態 | 日報義務 |
|---------|---------|
| 正社員・契約社員 | 原則必須 |
| 派遣・業務委託 | 任意（設定で変更可） |

---

## 3. 部署管理

**「部署管理」タブ**では、部署・チーム・ユニットの構成を管理できます。

### 階層構造

```
会社
 └── 部署（Department）
      └── チーム（部門チーム / ユニット）
```

### できること
- 部署・チーム・ユニットの新規作成・編集・削除
- チームへのメンバー追加・削除
- サブリーダーの設定

---

## 4. 日報管理

**「日報管理」タブ**では、全社のメンバーの日報を一覧・確認できます。

### 確認できる内容
- 本文（作業の記録）
- **タイムライン（カレンダーの予定が自動反映）**
- 勤務情報バー（始業・終業・休憩時間）
- コメント機能（フィードバック記入可）

> **ポイント：** 日報にはその日のカレンダー予定がタイムライン形式で自動表示されます。文章記録と予定表が同時に確認できます。

---

## 5. クライアント管理

**「クライアント管理」タブ**では、全社の取引先を管理できます。

### できること
- クライアントの新規登録・編集・削除
- 重複チェック（類似名の自動検知）
- 統合機能（複数クライアントを1つに統合）
- CSV でまとめて登録

---

## 6. 作業量分析

**「作業量分析」タブ**では、全社・部署・チームの作業量・負荷をスコアで可視化します。

### スコアの見方

| 指標 | 内容 |
|------|------|
| 総合ポイント（0〜600） | 6カテゴリの合計スコア |
| パーセンタイル（0〜100） | 同職種内での相対位置 |
| 偏差値（参考） | 全社を母集団とした分布上の位置 |

### 6つのカテゴリ

1. ステージ（作業のフェーズ・難易度）
2. サイズ（作業量の大きさ）
3. 種別（作業の種類）
4. 難易度（ページ単位の係数）
5. イベント（会議・外出などの時間）
6. 残業（通常・超過）

### できること
- 全社・部署別・チーム別の一覧表示
- 職種別ランキング
- 個人の詳細分析（期間指定）

---

## 7. 勤務形態設定

**「勤務形態設定」タブ**では、出勤・在宅・夜勤などのシフト種別を定義します。

- 各シフトに開始時刻・終了時刻・名称を設定
- 設定したシフトはユーザーの予定表（カレンダー）に反映される
- 夜勤シフト（開始が16時以降）は翌6時まで表示される

---

## 8. 勤務時間管理

**「勤務時間管理」タブ**では、全社の勤務記録（始業・終業・休憩）を確認・管理できます。

---

## 9. Admin権限管理（代表Adminのみ）

**「Admin権限管理」タブ**では、同じAdminロールを持つユーザーの権限フラグを管理できます。

### 設定できる権限フラグ

| フラグ | 内容 |
|--------|------|
| 会社管理 | 会社情報の閲覧・編集 |
| ユーザー管理 | ユーザーの登録・編集・削除 |
| 部署管理 | 部署・チーム構成の管理 |
| 日報管理 | 全社の日報確認・コメント |
| クライアント管理 | 取引先の管理 |
| 作業量分析 | 作業量スコアの閲覧 |
| 勤務形態設定 | シフト種別の定義・編集 |
| 勤務時間管理 | 勤務記録の閲覧・編集 |

---

## 10. Leader権限管理

**「Leader権限管理」タブ**では、Leaderロールを持つユーザーの権限フラグを管理できます。

設定できる権限は、Leaderマニュアルの「Leader権限管理」セクションを参照してください。

---

## よくある質問

**Q. タブが表示されない**
→ Admin権限フラグが付与されていない可能性があります。代表Adminの「Admin権限管理」で設定してもらってください。

**Q. ユーザーを削除できない**
→ 日報・ジョブなどのデータが紐づいている場合は削除できない場合があります。まずデータの移行・整理を行ってください。

**Q. 作業量分析にデータが出ない**
→ 集計期間内に完了したジョブ・日報の記録が必要です。まだデータが少ない場合は時間をおいて確認してください。
