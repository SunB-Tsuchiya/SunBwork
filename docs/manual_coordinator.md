# SunBWork コーディネーターマニュアル

---

## コーディネーターの役割

コーディネーターは、クライアントからの案件を登録・管理し、必要な作業（ジョブ）を担当ユーザーに割り当てる役割を担います。
ユーザーが作業を進められるよう、ジョブの内容・締め切り・優先度を整えて配置することが主な業務です。

---

## 画面の見方

ログイン後、上部に以下のタブメニューが表示されます。

| タブ | 内容 |
|------|------|
| **クライアント管理** | 取引先（クライアント）の登録・編集 |
| **案件一覧** | 担当している案件（プロジェクト）の一覧 |
| **ジョブ一覧** | ユーザーへの割当状況・メッセージの確認 |
| **案件カレンダー** | 全案件をカレンダーで俯瞰表示 |

---

## 基本的な使い方の流れ

```
クライアントを登録する
        ↓
案件（プロジェクト）を登録する
        ↓
案件の中にジョブ（作業タスク）を作成する
        ↓
ジョブをユーザーに割り当てる（メッセージ付き）
        ↓
「ジョブ一覧」で進捗・完了を確認する
```

---

## 1. クライアントを登録する

**「クライアント管理」タブ → 新規登録**

- クライアント名・担当者・連絡先などを入力します
- 登録時に名前の重複チェックが自動で行われます（同一名はブロックされます）
- CSV でまとめて登録することもできます

> クライアントを削除する場合、紐づいている案件がある場合は削除できません。代わりに「統合」機能で別のクライアントに案件を移行できます。

---

## 2. 案件を登録する

**「案件一覧」タブ → 新規作成**

| 項目 | 内容 |
|------|------|
| クライアント | 上で登録したクライアントを選択 |
| 案件名 | プロジェクトのタイトル（重複チェックあり） |
| サブコーディネーター | 共同で管理するコーディネーターを複数追加可 |
| メモ | 案件に関するノート |

> 案件名の登録時に似たタイトルが存在する場合、警告が表示されます（「それでも登録する」か「タイトルを変える」かを選択できます）。

---

## 3. ジョブ（作業タスク）を作成してユーザーに割り当てる

**「案件一覧」→ 案件を選択 → 「ジョブ一覧」**

### ジョブの作成

1. 「新規割当」ボタンを押す
2. 以下の項目を入力する

| 項目 | 内容 |
|------|------|
| タイトル | 作業の名称 |
| 担当者 | 割り当てるユーザー（複数選択可） |
| 締め切り日 | 希望する完了期限 |
| 作業種別 | 作業の種類（ステージ・サイズ・種別など） |
| メッセージ | 担当者へのコメント・指示 |

3. 「送信」を押すと、担当ユーザーのジョブボックスに届きます

### ポイント

- 派遣・業務委託のユーザーにはオレンジ色の警告が表示されます（雇用形態の確認を促します）
- 割り当て後もジョブの内容・締め切りを編集できます

---

## 4. 進捗を確認する（ジョブ一覧）

**「ジョブ一覧」タブ**で、割り当てた全ジョブの一覧と進捗状況を確認できます。

| ステータス | 意味 |
|-----------|------|
| 受信済み | ユーザーにまだ確認されていない |
| 確認済み | ユーザーが内容を確認した |
| 進行中 | 作業中 |
| セット済み | ユーザーが予定表にスケジュールを組んだ |
| 完了 | 作業完了 |

---

## 5. 案件カレンダーで全体を把握する

**「案件カレンダー」タブ**では、担当全案件の締め切り・スケジュールをカレンダー上で色分け表示します。

- 最大12色の自動割り当てで案件を区別
- 「完了済み案件を非表示」チェックで絞り込み可能

---

## 6. スケジュール（ガントチャート）

案件の詳細ページから「スケジュール」を登録でき、ガントチャート形式でプロジェクトの工程を管理できます。

---

## 7. その他の機能

### メッセージ・チャット
- ユーザーとのやりとりはメッセージ・チャットで行えます

### AI チャット
- 案件に関するサポートや文章生成にAIアシスタントを利用できます

---

## よくある質問

**Q. ジョブがユーザーに届かない**
→ ユーザーが「依頼されたジョブ」タブを確認するよう伝えてください。

**Q. 複数の案件を同じコーディネーターで共同管理したい**
→ 案件の編集画面でサブコーディネーターを追加できます。

**Q. クライアントを誤って登録してしまった**
→ 案件が紐づいていなければ削除できます。紐づいている場合は「統合」機能で正しいクライアントに移行してください。
