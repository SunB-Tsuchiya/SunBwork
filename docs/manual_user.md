# SunBWork ユーザーマニュアル（一般ユーザー向け）

---

## SunBWork とは

SunBWork は、日々の仕事（ジョブ）を管理し、予定を立て、作業を記録するための業務支援システムです。
コーディネーターから仕事を受け取るだけでなく、自分で仕事を登録して進めることもできます。

---

## 画面の見方

ログイン後、上部にタブメニューが表示されます。

| タブ | 内容 |
|------|------|
| **マイジョブ** | 自分で登録したジョブの一覧 |
| **依頼されたジョブ** | コーディネーターから割り当てられたジョブの一覧 |
| **日報一覧** | 作成した日報の履歴 |
| **予定表** | カレンダー形式の予定表 |
| **設定** | 勤務形態・表示設定 |

---

## 基本的な使い方の流れ

```
コーディネーターがジョブを配置
        ↓
「依頼されたジョブ」に通知が届く
        ↓
内容を確認して予定表にスケジュールを組む
        ↓
作業を進める
        ↓
日報に作業内容を記録する
```

---

## 1. ジョブを受け取る（依頼されたジョブ）

コーディネーターからジョブが割り当てられると、**「依頼されたジョブ」タブ**に表示されます。

**できること：**
- ジョブの内容・締め切り・担当者コメントを確認する
- 作業が完了したら「完了」ボタンを押す

**ステータスの意味：**
| ステータス | 意味 |
|-----------|------|
| 受信済み | 割り当てられたがまだ着手していない |
| 進行中 | 作業中 |
| 確認済み | 内容を確認した |
| セット済み | 予定表にスケジュールを組んだ |
| 完了 | 作業完了 |

---

## 2. 自分でジョブを登録する（マイジョブ）

コーディネーターからの依頼がなくても、自分の作業を自分で登録して管理できます。

**「マイジョブ」タブ → 新規登録**

入力項目：
- 作業名・案件名
- 締め切り日
- 作業種別・サイズ・ステージ（ワークロード計算に使用）
- メモ

---

## 3. 予定表にスケジュールを組む（予定表）

**「予定表」タブ**で、カレンダー形式のスケジュール管理ができます。

**できること：**
- ジョブの作業予定をカレンダーに登録する
- 「イベント（予定）」を新規作成する
- 勤務シフト（出勤・在宅・休暇など）を確認する

**スケジュールの登録方法：**
1. カレンダーの日付をクリックする
2. 「イベントを作成」が開く
3. タイトル・時間帯・関連ジョブを入力して保存する

---

## 4. 日報を書く（日報一覧）

**「日報一覧」タブ → 新規作成**

日報を作成すると、**その日に予定されていた予定表が日報の中に表示されます。**
作業内容を文章で記録しながら、タイムライン形式でその日の予定を確認できます。

**日報に含まれるもの：**
- 本文（Quillエディタで自由記述）
- その日のタイムライン（カレンダーの予定が自動反映）
- 勤務情報バー（始業・終業・休憩時間）
- コーディネーター・リーダーからのコメント

**日報を書く習慣のすすめ：**
毎日日報を書くことで、リーダーやコーディネーターに作業進捗が伝わり、評価や分析にも活用されます。

---

## 5. その他の機能

### メッセージ
- コーディネーターや他のユーザーからのメッセージを受信・返信できます
- 仕事の依頼（ジョブリクエスト）も届きます

### チャット
- チャットルームでリアルタイムに連絡が取れます

### AI チャット
- わからないことをAIアシスタントに質問できます

---

## 設定（勤務形態）

**「設定」タブ**で、自分のデフォルト勤務形態（出勤・在宅・夜勤など）を設定できます。
設定した勤務形態は予定表のカレンダーに反映されます。

---

## よくある質問

**Q. ジョブが届かない**
→ コーディネーターに確認してください。「依頼されたジョブ」タブを確認してください。

**Q. 日報にタイムラインが出ない**
→ 予定表にその日のイベント（予定）が登録されていないと表示されません。先に予定を登録してください。

**Q. 完了したジョブが消えてしまった**
→ 完了済みジョブは一覧に残りますが、フィルターで非表示になっている場合があります。
