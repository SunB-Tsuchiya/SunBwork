# 社員情報 概要（総務向け）

更新: 2026-10-17 ／ 状態: **実装済み（動作確認中）**。内容は打ち合わせで変わることがあります。
サンエー印刷・サン・ブレーン**両社**の社員について、総務が管理する情報（マイナンバー・住所・最寄り駅など）を、権限のある人だけが見られる形で持つメニューです。年末調整は、ここにある情報を使います。

---

## 1. ユーザー情報との違い

| | ユーザー情報 | 社員情報 |
|---|---|---|
| 場所 | 管理者の「ユーザー管理」 | 総務の「社員情報」タブ |
| 内容 | 氏名・メール・部署・雇用区分・ロール（ログインに必要な基本情報） | フリガナ・生年月日・社員番号・住所・世帯主・最寄り駅・マイナンバー |
| 見られる人 | 管理者 | **権限を与えられた総務・経理**（と管理者） |
| 編集する人 | 管理者 | 権限を与えられた総務（従業員は直接編集できません） |

- 社員情報は、ユーザー（ログインできる人）と1対1でつながります。ユーザーを登録すると、社員情報の一覧に自動で出ます。
- ユーザー情報の氏名・部署などは、社員情報の画面に表示されるだけで、ここでは編集しません。

## 2. 見られる人（権限）

管理者が、管理者メニューの「社員情報権限管理」で、総務・経理の担当者ごとに設定します。

| 権限 | できること |
|---|---|
| 社員情報を見る | 住所・最寄り駅などの一般項目を見られます。 |
| 社員情報を編集する | 一般項目を入力・更新できます。 |
| マイナンバーを見る | マイナンバーの全文を表示できます。 |
| 年末調整を管理する | 年末調整の受付・回収・確認・代理入力ができます。 |

- **権限が設定されていない総務・経理は、何も見られません。**
- **管理者は、一般項目を常に見て編集できます。** マイナンバーだけは、管理者にも「マイナンバーを見る」権限の設定が必要です。

## 3. 画面でできること

| 画面 | 内容 |
|---|---|
| 社員情報の一覧 | 両社の社員を、**サンエー印刷／サン・ブレーンのタブで切り分けて**表示します。 |
| 社員情報の編集 | フリガナ・生年月日・社員番号・住所・世帯主・最寄り駅・マイナンバーを入力します。 |
| マイナンバーの表示 | 普段は伏せ字（下4桁のみ）。「表示する」を押したときだけ全文が出ます。 |
| 権限管理（管理者） | 担当者ごとに、上の4つの権限をオン・オフします。 |
| 閲覧記録（管理者） | マイナンバーの全文を、だれがいつ、だれの分を見たかを確認できます。 |

## 4. 個人情報の扱い

- マイナンバーは暗号化して保存します。全文を表示したときは、必ず記録されます（だれが・いつ・だれの番号か）。
- **試用中はダミーの番号だけを使います。**
- 退職などでユーザーを削除しても、社員情報は消えません。7年間の保存義務があるため、消すのは7年経過後に、管理者が明示的に行います。

## 5. 年末調整との関係

- 年末調整の入力画面では、社員情報の内容が初期値として表示されます（住所・生年月日など）。
- 本人のマイナンバーも社員情報から引き継ぎ、提出時にその時点の番号を申請にも暗号化して保存します（過去の申告は、あとで社員情報が変わっても変わりません）。
- 従業員が年末調整で入力した住所などが、社員情報と違う（または社員情報が未登録の）ときは、年末調整の回収状況に「社員情報に差異あり」と出ます。総務が、項目ごとに、どちらが正しいか選んで、社員情報に反映できます（社員情報を編集する権限が必要です）。

## 6. これまでに決めたこと（質問と答えの要約）

| # | 質問 | 決めたこと |
|---|---|---|
| 1 | マイナンバーの置き場所 | 社員情報に暗号化して保存。年末調整の提出時に申請へコピーします。 |
| 2 | 誰が入力・更新するか | 権限のある総務だけ。従業員は直接編集できません。 |
| 3 | 管理者の閲覧権限 | 管理者は一般項目は常に可。マイナンバーだけ権限が必要です。 |
| 4 | 持つ項目 | 当面は、フリガナ・生年月日・社員番号・住所・世帯主・最寄り駅・マイナンバー。追加は総務と相談します。 |
| 5 | 権限の粒度 | 上の4つ。権限がなければ何も見られません。 |
| 6 | マイナンバー閲覧の記録 | 全文を表示したら必ず記録。管理者が確認できます。 |
| 7 | 退職者の扱い | ユーザーを削除しても社員情報は消えません。 |
| 8 | 対象範囲 | 両社の全ユーザー（登録された人は自動で一覧に出ます。SuperAdmin も所属会社の社員として含みます）。 |
| — | ユーザー情報との分離 | ユーザー情報（管理者の「ユーザー管理」）と社員情報は、別にします。 |
| — | 両社の扱い | サンエー印刷の総務がサン・ブレーンの総務も兼ねるため、両社を扱い、画面で会社ごとに切り分けます。 |

## 8. 総務にご確認いただきたいこと

- 総務が持っている社員データ（Excelなど）の形式と、含まれる項目。
- 社員情報に追加したい項目（電話・緊急連絡先・入社日・交通費・銀行口座など）。
- 「社員情報を見る」「編集する」「マイナンバーを見る」「年末調整を管理する」の権限を、だれに与えるか。
- マイナンバーを実際に扱う時期と、保管・取り扱いの社内ルール。
