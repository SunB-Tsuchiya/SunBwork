## 現在の事実

- 現行試用点 `trial_time_v2` は時間点が大きく、残業・案件登録・管理を別加点。新旧ガイドの依頼範囲の画面・文言は利用者確認済みだが、点数式、職種差、長い枠、予定・会議、上長照合は未完成。`WORKLOAD_REBUILD_MANAGER1.md` には、記録が約9割そろう前提で「時間より完了した作業・工程を主な比較材料にする方向」の利用者意向がある。現行 `work_units` は工程候補で完了数ではなく、自動 `completed` を成果とみなさない。この既存意向から E2 を具体化し、最初から主軸を聞き直さない。
- 仕事の時間割として使った通常予定が現行試用点に入らない事例がある。P17 は後回しではなく評価設計の論点。private の内容を無断で公開しない。
- 過去は D14 に従い網羅調査・一括再採点しない。8月の欠測有無や9月の個別照合は既に記録済み。具体的なバグを切り分ける時だけ過去の対象を絞る。
- 大まかな案件、マイジョブモーダル、依頼フォームには Super Admin 試用と確認済み箇所がある。一般公開・入力改善・統合はロードマップの後段。別作業者の変更を保護する。
