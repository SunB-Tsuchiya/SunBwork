## 2. 前年引継ぎの設計案（扶養控除等「異動」申告書の性質に合わせる）
- 扶養控除等申告書は「異動」申告書。前年の配偶者・扶養親族を読み込み、**行ごとに「変更なし / 変更あり / 削除」** を選ぶ。新規追加は「異動事由（結婚・出産・就職 等）」と異動月日を入力
- 保険料控除は毎年の金額が変わるため、契約情報（会社名・種類・契約者 等）だけコピーし、**払込保険料は空にして今年分を入力**
- 本人情報は社員プロフィール（住所録の土台）から初期表示

## 3. 会社側が持つ情報（従業員に入力させない）
所轄税務署、所轄市区町村、給与の支払者（名称・法人番号・郵便番号・所在地）、控除申告年分、提出年月日、ID（社員番号等）→ **会社設定／受付設定／ユーザー情報から自動で埋める**（受付作成時に総務が設定）

## 4. サンプルでは保存対象外にする項目
- 控除額（計算結果）: 配偶者控除の額、基礎控除の額、各保険料控除額、各合計額（決定 10）
- 控除証明書のインポート関連: インポートしたファイル名・出力ファイル名・ファイルハッシュ値・加工有無・（変更前）金額（後回し D-1）

## 5. データ構造の案
| テーブル（`suna_ga_nencho_*`） | 内容 |
|---|---|
| `employee_profiles`（※ `suna_ga_employee_profiles`。住所録の土台） | user_id(1:1)、company_id、氏名、フリガナ、生年月日、郵便番号、住所、世帯主 等 |
| `campaigns` | 受付: 年度、タイトル、開始日、締切、案内文、会社側情報（税務署・支払者 等） |
| `targets` | 受付の対象者（社員・契約社員を自動登録＋個別追加・除外） |
| `submissions` | 提出物 1 件: campaign_id、user_id、ステータス(下書き/提出済/差戻し)、入力者(本人/総務代理)、提出日時、本人・所得・区分の項目、**マイナンバー(暗号化)** |
| `spouses`（または submissions 内） | 配偶者 |
| `dependents` | 扶養親族（繰り返し） |
| `insurance_items` | 保険料控除の繰り返し行（種別: 生命一般/介護医療/個人年金/地震/社会保険/…） |
| `returns`（差戻し・履歴） | 差戻しコメント、日時、実施者 |
- 提出時に社員プロフィールの内容を submissions にスナップショット保存
