# MGinbon 出校表 再開プロンプト1

`MGINBON_SCHOOL_OUTING_PLAN1.md` と `MGINBON_SCHOOL_OUTING_MANAGER1.md` を読み、利用者承認後に `出校表_問題` を実装する。

添付FileMaker画像を基準に、A4縦1媒体1ページ、封筒貼付・手書き・押印用途とする。印刷モードは `空欄で印刷` を初期値とし、`現在値を反映` も選べる。識別情報は常に表示し、進行日付・担当・校了等だけを空欄化する。印刷操作でDBを更新しない。

既存レイアウトメニューへ追加するが、`for mac` は作らない。利用者向けカスタマイズ機能も作らない。Sakuraへはデプロイしない。
