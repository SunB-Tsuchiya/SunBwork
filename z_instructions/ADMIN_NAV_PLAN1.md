# SunBrain Adminタブ整理 設計

更新: 2026-11-12。利用者はサン・ブレーンだけの整理を指定し、サンエーは後日別途検討する。直前の相談で「権限管理」「4分類」「日報閲覧をダッシュボードの右」「勤務時間閲覧」「ポートフォリオ閲覧」を確認済み。

## 範囲

1. 既存のAdminナビを会社別部品に分離する。サンエーおよび会社タイプ未確定時は既存ナビをそのまま使い、サン・ブレーンの場合だけ新ナビを使う。Leaderナビは今回変更しない。
2. サン・ブレーンの上段は `ダッシュボード / 日報閲覧 / 人・組織 / 記録・分析 / 権限管理 / 各種設定` とする。日報は必ずダッシュボードの直後。上段の分類から、現在許可されている最初の下段ページへ進む。下段は既存URLを使う。
3. `人・組織`: 会社、ユーザー、部署、特別チーム、クライアント。`記録・分析`: 案件総覧、勤務時間閲覧、作業量分析、売上分析、ポートフォリオ閲覧。`権限管理`: Admin、Leader、日報、申請利用者、予定表。`各種設定`: 勤務形態、会議、在席ボード、会議室。閲覧系に書き込み可能な下位操作がある場合、その認可は既存のまま。
4. 表示条件は現在の `can(...)`、代表者判定、売上/ポートフォリオ許可、ルート存在判定を維持する。サーバのルート・認可・DBは変更しない。各画面のURL/ルート名を維持するため `lastTab_admin` の旧保存URLは有効。既存 `app.js` の404時の保存URL削除・Adminダッシュボード復帰を保持する。一般ユーザー向け仕事・案件の公開判断は対象外。
5. 共通画面のタイトルは `companyType === sunbrain` かつAdmin文脈だけ変更し、サンエー/Leaderは現状の文言を保つ。日報一覧、勤務時間一覧、ポートフォリオAdmin一覧を対象とする。

## 影響ファイルと検証

`resources/js/Components/Tabs/AdminNavigationTabs.vue` を会社別の分岐にし、一般会社用とSunBrain用の2部品を追加。共有のタイトルに触れるページだけ最小変更。専用の軽量ナビ検証を追加し、サンエーの既存タブと条件が保持されること、SunBrainの並び・下段・代表者/個別権限・モバイルとデスクトップの一致を確認する。対象ESLintと `/members` ビルドを行う。画面確認と本番反映は別状態。

保存基準: 本番画面確認済みの `a975c63e5` のアプリソースと隔離作業ブランチ。手元の `origin/main` には別作業でAdminポートフォリオ/売上利用設定、Leader大まかな案件を外す差分があり、今回の変更で戻したり混ぜたりしない。本番統合は配備前に再比較する。
