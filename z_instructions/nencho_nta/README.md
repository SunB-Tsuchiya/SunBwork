## 注意（設計図との違い）
- 帳票設計書は画面フローではなく **PDF 出力の項目定義**。質問順序・分岐は一次資料に無く、こちらで設計する（国の XML 定義の項目・型・桁数・コード値を満たす形で）
- XML 定義書には年調ソフトが計算する **控除額の項目**（配偶者控除の額・基礎控除の額・各保険料控除額 等）が含まれる。設計図は税額計算をしない方針 → 控除額項目の扱いは要決定
