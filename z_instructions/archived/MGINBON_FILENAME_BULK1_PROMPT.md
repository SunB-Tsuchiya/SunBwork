# 銀本 ファイル名一括工程登録 再開PROMPT1

`z_instructions/MGINBON_FILENAME_BULK_PLAN1.md` と `z_instructions/MGINBON_FILENAME_BULK_MANAGER1.md` を最初から読み、管理表の未完了項目から銀本ファイル名一括工程登録を続行する。

固定形式は `30812026__AASh.pdf` のように、Nコード4桁＋年度4桁＋`__`＋媒体記号＋教科記号＋`.pdf`。媒体は `Q=問題, A=解答のみ, AA=解説解答, Y=解答用紙, T=傾向と対策`、教科は `Ko=国語, Sa=算数, Sh=社会, Ri=理科`。`m` は使わない。

バッチごとに工程1つと日付1つを共通指定し、previewで一意一致・既存値・形式エラー・重複を確認してから登録可能行だけを一括反映する。既存値は初期値で上書きしない。新規DBテーブルは作らない。

再校校正は「校正①校正入／UP」と「校正②校正入／UP」の別項目とし、LIST名称と一括登録名称を一致させる。初期登録工程は合12項目。

既存未コミット変更と `storage/**` を保護する。Sakura SSH・migration・seed・deployは正確なコマンドを提示し、利用者の明示確認を得るまで実行しない。
