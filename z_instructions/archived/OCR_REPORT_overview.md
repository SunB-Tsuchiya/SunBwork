# OCR 改修 概要レポート

> 作成日: 2026-05-09

---

## ひとことで言うと

**「伝票画像の文字読み取りを、外部サービスに送らずサーバーの中だけで完結させた」**

---

## 何が問題だったか

これまでは **OCR.space** という海外の無料APIサービスを使って伝票画像を読み取っていました。

```
【従来の流れ】
伝票画像 → インターネット経由 → OCR.space（ドイツのサーバー）→ 文字データが返ってくる
```

無料プランのため「処理後にデータは削除する」とは書かれていますが、
重要な受注情報が含まれる伝票を外部に送ることへの不安がありました。

---

## どう解決したか

さくらサーバーの中に **Tesseract（テセラクト）** という
オープンソースの文字認識エンジンを直接インストールしました。

```
【改修後の流れ】
伝票画像 → さくらサーバーの中だけで処理 → 文字データ完成
                ↑
          外部には一切送らない
```

---

## さくらサーバーで行った作業

さくらの共有レンタルサーバーは管理者権限がないため、
通常の方法（`apt install` など）でソフトをインストールできません。

そこで **ソースコードからビルド（コンパイル）** する方法を取りました。

```
インストールしたもの（~/local/ フォルダ内）
├── Leptonica 1.82.0   … Tesseract が必要とする画像処理ライブラリ
├── Tesseract 5.3.4    … 文字認識エンジン本体
├── jpn.traineddata    … 日本語の学習データ（14MB）
└── eng.traineddata    … 英語の学習データ（15MB）
```

ビルドには gcc（コンパイラ）と cmake（ビルドツール）が
サーバーに入っていたため実現できました。

---

## システム上の変更点

**ファイルを3つ変更・1つ新規作成しただけで、既存の機能はほぼ触っていません。**

| ファイル | 何をしたか |
|---|---|
| `app/Services/LocalTesseractService.php` | **新規作成。** ローカルTesseractを呼び出す処理 |
| `app/Services/OcrSpaceService.php` | メソッドの可視性を少し変更（継承のため） |
| `app/Providers/AppServiceProvider.php` | どちらのOCRを使うか切り替える設定を追加 |
| `config/services.php` | Tesseractのパス設定を追加 |

---

## 切り替え方法

さくらサーバーの `.env` ファイルの1行を変えるだけで切り替えられます。

```
OCR_DRIVER=local       ← 今はこれ（さくらサーバー内で処理）
OCR_DRIVER=ocr_space   ← これに戻せば従来のAPIに切り替わる
```

もし Tesseract の調子が悪い時は `ocr_space` に戻せばすぐ復旧できます。

---

## 精度について

Tesseract は Google が開発したOCRエンジンで、
今回は精度重視の **tessdata_best** モデルを使っています。

ただし、**画像の品質（解像度・傾き・明るさ）に大きく左右されます。**
実際の伝票でテストして、読み取れないケースがあれば前処理の調整で改善できます。
