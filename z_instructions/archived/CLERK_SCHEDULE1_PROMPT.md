# Clerk予定の複製・予定日設定 引き継ぎ

AGENTS.md、CLAUDE.md、CLERK_SCHEDULE_PLAN1.md、CLERK_SCHEDULE_MANAGER1.mdとCONSOLIDATED_01/05を読む。
前回のClerk連続カレンダー・祝日設定はユーザー確認OK。今回の追加は複製と自動予定登録。
ユーザー承認後にCodexが実装・自動検証・ローカルmigrationまで完了。再実装せず、MANAGERの画面確認項目から続ける。

主な仕様:
- 予定詳細からタイトル・内容・色・期間を引き継いで複製し、日付変更後に新規保存。完了状態とルール紐づけは引き継がない。
- カレンダー設定に予定日設定。毎月の日付、月末、第N/最終曜日、個別日付の複数指定。
- 第N曜日はN回目。存在しない日はスキップ。休日の自動移動なし。
- 定義と生成履歴を会社単位で保存。保存・定期実行・表示時補充で実際のclerk_eventsを作る。
- 重複生成を防ぎ、個別編集・移動・削除・完了を保護。ルール変更・停止時も過去・完了・個別変更分を残す。
- 参考会議設定は次回日付を入力する実装なので、そのまま継続生成として流用しない。

既存AppLayoutとClerk紫のUIを踏襲。会議画面の入力部だけを参考にする。
売上分析・前回Clerk対応の未コミット差分を保護。Tests\TestCaseはsales DB削除処理を含むため使用禁止、このタスクは独立インメモリSQLiteでテスト。
追加migration 2件はローカル適用済み。PHP 12 tests / 95 assertions、JS 5 testsを2タイムゾーン、npm run buildが成功。更新履歴clerk-calendar-5もローカル反映済み。
ブラウザ操作と本番配備はプロジェクト規則に従う。本番では2件のmigrationと日次スケジューラの稼働を確認する。
