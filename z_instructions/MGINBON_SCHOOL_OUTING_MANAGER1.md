## 2026-09-25 初版実装

- レイアウトメニューへ `出校表_問題` を追加し、選択時は媒体 `問題` へ自動的に絞り込む。
- 現在ページの問題媒体を初期選択し、個別選択、全選択、解除、印刷・PDFに対応した。
- `空欄で印刷` を初期値とし、`現在値を反映` とのラジオ切替を追加した。
- 識別情報は両モードで表示し、日付・担当・備考・校了は空欄モードで非表示にする。DB更新は行わない。
- 添付原票に合わせ、基本情報、学校名、教科、掲載状態、入稿日、文字UP、工程13行、節目日付、作業時間手書き欄、校了欄をA4縦へ配置した。
- 現行14工程に存在しない五校赤字照合は手書き行だけを残し、別工程の担当者を誤表示しない。
- Docker内PHP構文検査、MGinbon 21 tests / 71 assertions、`npm run build`、`git diff --check`に成功した。
- さくら本番へは未デプロイ。次は利用者による画面・印刷プレビュー確認。

## 2026-09-25 原票寄せ・仕上げ調整

- 帳票全体の縦方向の余白、文字サイズ・太さ、学校名および工程欄をFileMaker原票に近づけた。
- 最上部の見出し枠は四隅すべてを角丸にした。

- `突き合わせ`、`初校チェック`、各赤字照合などの補助ラベルを工程枠内で縦中央揃えにした。
- 作図・初校・再校などの工程名枠は角丸を廃止し、すべて角形に統一した。
- `npm run build` と `git diff --check` に成功した。

## 2026-09-25 絞り込み修正

- `出校表_問題` 表示中に媒体条件を常に `問題` へ上書きしていた処理を廃止した。
- 出校表でも上部の媒体選択（問題、解答のみ、解説解答、解答用紙など）をそのまま一覧・印刷対象へ反映する。

## 2026-09-25 全教科・単教科印刷

- 利用者向けの帳票名を媒体に依存しない `出校表` へ変更した（内部の既存view識別子は互換性のため維持）。
- `全教科` は従来どおり媒体1件を1枚、`単教科` は媒体1件を国語・算数・社会・理科の4枚へ展開する。
- 単教科用紙の科目欄には4教科を表示し、対象教科だけ黒・太字、対象外を薄いグレーとして判別できるようにした。
- 現在値反映時の教科別日付・担当者は、単教科用紙では対象教科の値を使用する。

## 2026-09-26 帳票レイアウト調整

- 学校名を白い枠内へ表示し、従来の学校名下の白い横線を廃止した。
- `銀本掲載` の丸印を拡大した。
- 初校チェック・初校校正・再校校正など、左右に重複していた工程名は左側だけ残し、右側を担当者欄として広く使う。
- 帳票上部右端へ表示する `解答あり` / `解答なし` / 空欄を、出校表の印刷設定で選択できるようにした。DBには保存しない。
- `文字UP` の日付枠を列幅内へ収め、右側の備考枠を短くして余白を設け、両者が重ならないようにした。
- 工程行をFileMaker同様の固定5列（日付／工程名または補助文字／役割／担当者／作業時間）へ変更した。黒い作図・初校等を補助文字列へ、グレーのOPを校正名列へ左移動し、全行の白い担当者欄を同じ開始位置・同じ長さに統一した。
- ページを帳票レイアウト指定で直接開いた際、上部操作欄の生成前にTeleportが評価されてボタン類が表示されないことがあった。出校表と発注書のTeleportを遅延配置し、表示切替・選択・印刷ボタンを安定して表示するよう修正した。
- `解答あり` / `解答なし` は学校・媒体ごとに異なるため、一括セレクターを廃止し、各帳票の右上枠を個別ドロップダウンにした。単教科4枚では同じ媒体の選択値を共有し、印刷時は選択部品を出さず文字列として表示する。
- 印刷対象以外を隠すCSSが工程欄内の `space-y-3` にも一致し、工程13行を非表示にしていた。セレクターをページ直下のコンテナに限定し、出校表および発注書の帳票内部を隠さないよう修正した。
- 出校表画面の入稿日、文字UP、初校出、再校出、三校出、三校戻、四校出をクリック入力できる日付欄にした。`現在値を反映` の場合だけ保存可能で、`空欄で印刷` の場合は切替案内を表示して保存しない。全教科は全教科へ、単教科は対象教科だけへ既存の日付セルAPIで保存し、印刷帳票は読み取り表示のみとする。
- 工程行の担当者名と作業時間を一つの白枠へ統合し、作業時間の手書き欄を `（　　　）` に広げた。担当者名は標準ウェイト・16px、作業時間は11pxとした。グレーの役割欄を6.6remへ拡張し、OP・初校チェック・各校正名を13pxの一行表示に統一した。
- 左の日付欄と右の作業工程を一つの時系列として再構成した。初校チェック→初校出→初校校正、再校校正2工程→再校出→三校、三校校正→三校出→三校戻→四校、四校校正→四校出→五校の順にし、緑の日付欄は工程間のライン位置へ配置した。
- 初校出・再校出・三校出・三校戻・四校出の緑枠中央から右の工程列へ水平線を追加した。緑枠は高さ40px、ラベル11px・標準ウェイトへ縮小し、連続する三校出／三校戻も重ならない行間を確保した。工程行と余白、入稿日・文字UP・メモ欄も圧縮してA4内へ収める。
- 緑枠内の日付を上寄せし、ラベル行との間隔を縮めた。出校日の水平線は緑枠右端から帳票右端まで伸ばす。
- 三校戻はタイムライン工程から外し、三校出の直下に線なしの付随日付として配置した。三校出の中央線上へ四校工程を移し、左右の時系列を揃えた。
- FileMakerに合わせ、三校出の水平線と四校を同じ高さにせず、三校出線の下へ四校ブロック群を配置した。三校戻は三校出の下に線なしで付随表示する。四校出も独立した区切り線とし、その下へ五校ブロック群を配置する。
- 出稿表の担当者欄を、進行表と同じ案件チームメンバー＋外注先の候補セレクターにした。現在値反映時だけ仮担当を登録でき、全教科では編集可能な全教科、単教科では対象教科へ反映する。正式登録済み・進行中・完了済みは既存ルールどおり変更しない。
