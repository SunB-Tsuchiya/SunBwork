# MGinbon 年度別外注単価マスター 計画1

作成日: 2026-09-26
状態: 利用者確認待ち

## 1. 目的

銀本の年度、外注先、作業種別ごとの単価を登録し、既存の社外作図・社外スキャン点数から金額を安全にプレビューできるようにする。単価や外注先が未設定の明細を0円扱いせず、未計算として明示する。

## 2. 初版の範囲

- 年度プロジェクトごとの単価マスター画面
- 外注先ごとの作図単価・スキャン単価
- 単位は現行数量に合わせて `point`（点）
- 金額プレビューは `数量 × 税抜単価`
- 大連若葉作図発注書および外注先別集計から参照できる共通計算サービス
- 未設定単価、外注先未対応、数量0を区別する
- 登録・変更履歴をMGinbon変更履歴へ保存する

初版に含めないもの:

- 消費税計算
- 端数処理
- 締め日、支払月、請求確定
- 文字入力、組版、校正の単価（数量・単位が未確定）
- 過去支払額の会計確定

## 3. データ設計

### 3.1 `mginbon_subcontractor_rates`

- `id`
- `mginbon_project_id`（年度プロジェクト。MGinbon DB内FK）
- `subcontractor_id`（SBWork本体DBの外注先ID。DBをまたぐためFKは張らない）
- `work_type`（初版は `drawing` / `scan`）
- `unit`（初版は `point`）
- `unit_rate`（`decimal(12,2)`、0以上）
- `is_active`
- `created_by` / `updated_by`（本体DBユーザーID、FKなし）
- timestamps
- unique: 年度プロジェクト＋外注先＋作業種別＋単位

外注先IDは保存時・表示時に本体DBの会社スコープ付き候補集合で検証する。削除済み外注先でも過去行を壊さないよう、表示用名称スナップショット追加の要否を実装前に確認する。

### 3.2 数量明細の単価スナップショット

`mginbon_work_measurements`へ将来の確定用として次をnullable追加する。

- `unit_rate_snapshot decimal(12,2)`
- `amount decimal(14,2)`
- `rate_source_id`（単価マスター参照、nullable）
- `priced_at`（nullable）

初版の集計・帳票はマスター参照によるプレビューとし、勝手にスナップショットを確定保存しない。支払確定フロー決定後にスナップショット保存を有効化する。

## 4. 計算規則

- 対象は `execution_type = subcontracted`
- 数量0は金額0として表示可能
- 数量があり単価未設定の場合は金額を `未設定` とする
- 外注先IDがない場合は `外注先未設定` とする
- 単価は同年度・同外注先・同作業種別・同単位の完全一致のみ
- 他年度単価を自動流用しない
- 浮動小数点ではなくDecimal相当で計算する
- 税込金額、丸め済み支払額とは呼ばず、`税抜参考金額` と表示する

## 5. 管理画面

新規ページ: `Coordinator/MGinbon/Rates/Index.vue`

- `AppLayout`を使用
- 年度選択
- 外注先を行、作図・スキャンを列にしたコンパクトな表
- 単価入力、保存、未設定表示
- 0円と未設定を区別
- 銀本進行・集計へ戻る導線
- 保存成功／失敗は既存フラッシュ・グローバルトーストを使用

候補外注先は案件に登録済みの外注先を基本とし、既存単価行にのみ存在する外注先も過去表示から消さない。

## 6. 帳票・集計連携

- 大連若葉作図発注書: 外注先ごとの作図点数、単価、税抜参考金額、合計
- 集計: 外注先別に作図・スキャンの数量、単価設定状況、税抜参考金額
- 単価未設定を0円で集計しない
- 送付用帳票へ内部警告を混在させるかはFileMaker原票確認後に決める

## 7. 権限・監査

- 初版の閲覧・編集権限は既存MGinbon Coordinatorルートに合わせる
- 別会社の外注先IDを保存できないようサーバー側で検証
- 作成・変更・無効化を変更履歴へ記録
- 物理削除は行わず、無効化を基本とする

## 8. 実装予定ファイル

- MGinbon migration 2本（単価マスター、数量明細スナップショット列）
- `MGinbonSubcontractorRateController`
- 単価・金額計算サービス
- `resources/js/Pages/Coordinator/MGinbon/Rates/Index.vue`
- `routes/web.php`
- 銀本上部メニュー／集計／作図発注書の必要箇所
- Feature / Unit tests
- 管理・統合ドキュメント

## 9. 検証

- 専用一時SQLiteへMGinbon migrationを適用
- 年度・外注先・作業種別の一意性
- 会社スコープ外の外注先拒否
- 未設定／0円の区別
- 数量×単価のDecimal計算
- 他年度単価を流用しない
- 帳票・集計の件数と合計
- `npm run build`
- `git diff --check`

## 10. 利用者確認資料

可能なら以下のFileMakerスクリーンショットを受領する。

1. 外注先単価を登録している画面
2. 作図発注書で単価・金額が表示される部分
3. 外注費を集計している画面または帳票

個人情報や実金額を伏せた画像でもよい。画像がない場合もマスター初版は実装可能だが、帳票列と会計表示名の確定は画像確認後とする。
