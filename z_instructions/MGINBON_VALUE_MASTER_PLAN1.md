# MGinbon 値一覧マスター 計画1

作成日: 2026-09-26
状態: 利用者確認待ち

## 1. 目的

FileMakerの「値一覧の管理」に相当するWeb管理ページを作り、銀本で使う選択肢を年度ごとに新規追加、編集、無効化、並べ替えできるようにする。

## 2. 対象一覧（提供画像の13項目）

1. チェック担当者
2. 作業担当 作図・文字入力
3. 作業担当 組版
4. 原本scan担当
5. 原本画像サシカエ
6. 媒体分類
7. 学校分類
8. 支払月
9. 文字校正担当
10. 日能研分類
11. 科目
12. 解答あり・なし
13. 銀本掲載

初期値は2026年FileMaker画像を基礎に移す。ただし小さく判読が不確かな担当者名は推測せず、拡大画像またはテキスト確認後に登録する。

## 3. データ構造

### `mginbon_value_lists`

- `id`
- `mginbon_project_id`（年度）
- `code`（固定内部コード）
- `name`（画面表示名）
- `sort_order`
- `is_active`
- timestamps
- unique: 年度＋code

### `mginbon_value_list_items`

- `id`
- `mginbon_value_list_id`
- `value`（FileMaker原文を保持）
- `sort_order`
- `is_active`
- `linked_user_id`（本体DBユーザー、nullable、DB間FKなし）
- `linked_subcontractor_id`（本体DB外注先、nullable、DB間FKなし）
- `created_by` / `updated_by`
- timestamps
- unique: 一覧＋value

担当者候補は文字列だけでも保存可能とするが、実際の仮担当登録に使用する候補はユーザーまたは外注先へ紐付いた項目を優先する。旧文字列を名前一致で自動確定しない。

## 4. 管理画面

新規ページ: `Coordinator/MGinbon/ValueMasters/Index.vue`

- AppLayoutを使用
- 年度選択
- 左側に13種類の一覧
- 右側に選択中一覧の値
- 新規追加
- 値の編集
- 有効／無効
- 上下移動または表示順入力
- ユーザー／外注先への任意紐付け
- 削除は原則行わず無効化
- 同じ年度・一覧内の重複値を拒否

FileMakerの自由な一覧名追加は初版では行わず、一覧種別13個はコード側で固定する。値だけを管理可能にする。新しい業務一覧が必要になった場合は正式なコード改修で追加する。

## 5. 年度運用

- 年度作成時に標準一覧を生成
- 前年度コピーは明示操作で行い、自動複製しない
- コピー後も年度ごとに独立して編集可能
- 既に進行データへ使用された値を無効化しても過去表示は維持

## 6. 既存正規マスターとの関係

- `媒体分類` は `mginbon_media_types` と整合させる
- `科目` は `mginbon_subjects`の組み合わせ表示候補として扱い、教科コード自体は固定4教科を正本とする
- `学校分類`・`日能研分類` は制作単位の入力候補
- 担当者系は `ProjectJobAssigneeOptions` と連携し、候補区分マスターの基礎にする
- `解答あり・なし`、`銀本掲載` は帳票・媒体編集の候補

値一覧だけを正本にして正規テーブルを壊さず、各入力欄が参照する候補レイヤーとして使う。

## 7. 権限・監査

- 初版はMGinbon Coordinator管理ルート
- 会社スコープ外ユーザー・外注先への紐付けを拒否
- 作成、編集、並べ替え、無効化、紐付け変更を監査ログへ記録
- 物理削除は提供しない

## 8. 初期値移行

- 判読できる定型値（媒体分類、学校分類、支払月、日能研分類、科目、解答あり・なし、銀本掲載）を画像から転記
- 担当者名・会社名は誤字防止のため拡大画像またはテキスト一覧で確認
- 文字列は全角半角、記号、末尾スラッシュを勝手に正規化しない
- 初期投入は冪等Seederまたは年度初期化サービスで行う

## 9. 実装予定

- MGinbon migration
- 値一覧初期化サービス
- Controller / validation / routes
- Inertia管理ページ
- 銀本メニュー導線
- 既存入力候補への段階的接続
- Feature tests / frontend build

## 10. 検証

- 年度間で値が混ざらない
- 重複拒否
- 並び順
- 無効値の新規選択除外と過去表示維持
- 会社スコープ外リンク拒否
- 前年度コピーは明示操作のみ
- 一時SQLiteのMGinbon DBでテスト
- `npm run build` / `git diff --check`
