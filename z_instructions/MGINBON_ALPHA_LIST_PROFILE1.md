# 2026年度 α版対象校リスト解析

## 1. 対象ファイル

- `z_NDBSystem/N_DBSystem_DDR/2026年度のα版対象校リスト.xlsx`
- シート: `2026`
- 範囲: A1:E178
- データ行: 177行

| 列 | 内容 |
| --- | --- |
| A | みくにコード |
| B | 日能研コード |
| C | α版区分 |
| D | 学校名 |
| E | 入試回（掲載用） |

学校名等のふりがながルビとして埋め込まれたセルがある。低水準XML解析でルビ文字を本文へ
連結しないこと。実装では既存依存のPhpSpreadsheetを使って表示本文を取得する。

## 2. α版対象

C列を空白除去して判定した結果、α版対象は63掲載行。

| 区分 | 件数 | FileMaker日能研分類 |
| --- | ---: | --- |
| ① | 13 | α版-1 |
| ② | 16 | α版-2 |
| ③ | 13 | α版-3 |
| ④ | 17 | α版-4 |
| 関西 | 4 | α版 関西4校 |
| 合計 | 63 |  |

業務上、関西は関西の人気校、①は最難関校を中心とする人気校群、②は主として男子校、
③は主として女子校、④は主として共学校である。

区分とみくにコード帯には例外があるため、コード帯からα区分を推測しない。年度ExcelのC列を
正本とする。①～④の件数を固定上限にせず、年度ファイルの実数を取り込む。

## 3. FileMaker全件との照合

`NDBSystem_2026_全件全項目.mer`とのみくにコード照合結果:

| 内容 | 件数 |
| --- | ---: |
| Excel掲載行／一意みくにコード | 177 |
| FileMaker一意みくにコード | 177 |
| 一致した掲載行 | 177 |
| 不一致・欠落 | 0 |
| コード付きFileMakerレコード | 529 |
| コードなし冊子共通レコード | 6 |

このExcelはα版指定だけでなく、年度の学校・入試回別制作対象一覧として利用できる。
コードなし6件の冊子共通制作物はExcel対象外として別に生成・移行する。

α版63掲載行に対応するFileMaker媒体:

| 媒体 | レコード数 | 用途 |
| --- | ---: | --- |
| 問題 | 63 | α版デジタル構成 |
| 解説解答 | 63 | α版デジタル構成 |
| 解答用紙 | 63 | α版デジタル構成 |
| 傾向と対策 | 57 | α版デジタル構成。学校単位 |
| 解答のみ | 55 | 書店向け解答冊子用。α版4点セットとは別用途 |

| 媒体構成 | 掲載行数 |
| --- | ---: |
| 4つのα媒体すべて＋解答のみ | 55 |
| 問題・解説解答・解答用紙のみ | 6 |
| 上記3媒体＋傾向と対策（解答のみなし） | 2 |

傾向と対策は年度×学校で1つである。人気校の第二回・別日程が別掲載行になる場合、第二回側には
傾向と対策を付けない。2026年度の第二回等に当たるみくにコード239～244・350のうち、
α対象の6掲載行に傾向と対策がないことをFileMakerデータで確認した。各校の代表掲載行側には
傾向と対策が存在する。

したがって、この6件は媒体欠落ではない。問題・解説解答・解答用紙は入試回単位、傾向と対策は
学校単位として商品構成へ接続する。存在しない媒体を空レコードで補わない。

## 4. みくにコード帯

| コード帯 | 年度版掲載分類 |
| --- | --- |
| 100番台 | 共学 |
| 200番台 | 男子校 |
| 300番台 | 女子校 |
| 500番台 | 地方校 |

この分類は既存`n_publication_entries.publication_section`に対応する。恒久学校の性別属性や
α版区分としては使わず、年度版掲載上の分類として保持する。

プロジェクト自体は関東の私立中学入試問題集である。ただし年度リストには地方校等も掲載される。
地域・学校種別から行を自動除外せず、年度リスト掲載行を制作対象の正本とする。

## 5. 取込方針

1. 年度はシート名または取込画面の指定値から取得する。
2. A～E列を見出し名で解決し、固定列位置だけに依存しない。
3. 年度＋日能研コードで`n_exams`を照合する。
4. 年度版＋みくにコードで`n_publication_entries`を照合する。
5. 両者の`school_id / exam_id`整合を検証する。
6. 既存NSystemで管理済みの共有コード等の例外はNSystem側の掲載行を使う。
7. C列が①～④・関西なら年度αグループを作る。空欄は通常掲載行。
8. FileMaker媒体レコードと結合し、実在する商品構成だけを生成する。
9. 原文、元行番号、ファイルハッシュ、取込回、警告、確定者を監査保存する。

年ごとに同形式が想定されるが、見出し不足、未知のα区分、重複コード、NSystem不一致を検知し、
プレビュー確認後に確定する。
