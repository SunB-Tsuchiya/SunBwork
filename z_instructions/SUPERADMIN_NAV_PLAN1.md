# SunBrain Super Adminタブ整理 設計

更新: 2026-11-13。利用者はAdmin・Leaderの画面確認後、Super Adminも基本的に同じ形式で整理すると指定。確認質問で、現行にない日報閲覧の入口は追加しないと決定。

## 範囲と配置

- 会社別部品へ分け、`companyType === 'sunbrain'` の時だけ新しいSuper Adminナビを使う。一般会社・会社未選択時は現在の部品を原文のまま使う。
- SunBrainの上段は「ダッシュボード / 仕事・案件（試用） / 人・組織 / 記録・分析 / 権限管理 / 各種設定」。仕事・案件（試用）は現在の `userWorkHub.enabled` 等の条件を維持する。
- 人・組織: 会社の追加と管理、グループ会社設定、会社・部署設定、ユーザー管理、Adminユーザー管理、役職称号管理。
- 記録・分析: 大まかな案件、作業量分析、売上分析。大まかな案件を先頭にし、開けるときは親タブの着地点にする。作業量分析は今と同じ別タブで開く。大まかな案件の試用条件を維持する。
- 権限管理: Admin権限管理、売上分析 利用許可設定、申請者管理。申請者管理は現行のAdminエリアへ移動する挙動を保持。
- 各種設定: AI設定、スクリプト管理、デモページ管理、APIデバッグページ。
- 現行18入口のルート名・URL・表示条件・別タブ条件は維持する。デスクトップとモバイルで同じ定義を使う。現行にない日報閲覧リンクや一般ユーザーへの試用公開を追加しない。
- `lastTab_superadmin` の旧URLは有効。404時に保存先を消してダッシュボードへ戻る既存処理を保持。サーバーのルート、認可、DBは変更しない。

## 作業と確認

`SuperAdminNavigationTabs.vue` を会社別分岐にして、旧表示用とSunBrain用を追加する。旧表示用と元部品の同一性、18入口と条件、別タブ、モバイル・デスクトップの一致、`/members`ビルドと資産参照を確認する。実装、配備、利用者の実画面確認は `SUPERADMIN_NAV_MANAGER1.md` で分ける。
