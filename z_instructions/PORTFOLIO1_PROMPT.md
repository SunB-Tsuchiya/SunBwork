# PORTFOLIO1_PROMPT.md — 新セッション開始用プロンプト

以下を新しいセッションの最初にそのまま貼り付けて使用すること。

---

```
デザイナー用ポートフォリオ機能（PORTFOLIO）を継続します。
まず z_instructions/PORTFOLIO_PLAN1.md と PORTFOLIO_MANAGER1.md を読んでください。
CLAUDE.md の作業ルール（設計確認→実装、質問は1つずつ、npm run build、docker は --user sail）も守ること。

## 目的
制作担当者（デザイナー）が客先で自分の作品（PDF/JPG/動画）を見せる。個人専用・SB専用。
閲覧ページは銀本進行/売上分析のように別タブ・ヘッダーなしの全画面。

## 確定仕様（要約）
- 個人ごと・ログイン本人のみ（共有リンクなし）・オンライン前提
- コレクション＋タグで整理。作品情報はタイトル＋説明
- 画像=サーバー縮小 / PDF=サーバーでページ画像化（Imagick+gs 利用可・N枚ずつ処理）/ 動画=アップ前にブラウザ圧縮（さくらに ffmpeg なし）
- 分割アップロード（Web側アップロード上限対策）
- 管理画面（AppLayout）と閲覧ページ（独立レイアウト）を分離
- トップ=コレクション表紙一覧 → スライドショー。スワイプ/キー操作、PDFは見開きページめくり
- 白＋モノトーン＋デザイナーが選ぶワンポイントカラー
- 権限: portfolio_permissions（売上分析の権限画面を踏襲）＋雇用区分/ロール/部署で絞り込み。初期は SuperAdmin のみオン
- ルートは deny_general。ファイルは storage/app/portfolio 配下に置き、認証付きで本人にだけ配信
```
