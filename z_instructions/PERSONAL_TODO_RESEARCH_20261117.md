# 個人TODOを整理しやすくするための調査・提案

2026-11-17。基準ae6e6188b。branch feature/personal-todo-rich-research-20261117。依頼は調査と提案、実装承認/一般公開の承認ではない。現行個人月/TODOは情報出版SuperAdmin限定、保存/期限/完了とサイドバー3条件を利用者確認済み。成功済み試験は反復しない。

## 利用者要望（確定）
OutlookやTODOアプリのように多少リッチで使いやすくしたい。左側は一覧/直近確認、編集/設定/整理は別ページで行える形を検討。複数の代表アプリと機能を調査して提案する。

- Microsoft Outlook/To Do: https://support.microsoft.com/en-us/outlook/calendar/manage-tasks-with-to-do-in-outlook
  今日の計画My Day、重要スター、予定済み/全件/完了等の一覧、期限/リマインダー/繰返し、ステップ、メモ。My Dayに入れても元リストで管理する。
- Microsoft To Doのステップ等: https://support.microsoft.com/en-us/todo/add-steps-importance-notes-tags-and-categories-to-your-tasks
  細かなチェック項目と完了数、重要/ノート/タグ、メモの書式。
- Todoist: https://www.todoist.com/help/todoist/features/introduction-to-filters-V98wIH
  日付/ラベル/優先度/プロジェクト/キーワード等の条件で保存した絞込。個人向けSunBWorkへは複雑なクエリ入力ではなく選択式で応用する案。
- TickTick: https://ticktick.com/features
  カレンダーと、分類リスト→タスク→詳細の3列表示。複数表示形式のうちSunBWorkはまずリスト+詳細が適するとの推奨で、ボード化を確定しない。
- Google Tasks: https://support.google.com/tasks/answer/7675838?co=GENIE.Platform%3DDesktop&hl=en
  カレンダー/サイドパネルから追加、詳細、日付/時刻、締切、繰返し、サブタスク。実行の開始日時とdeadlineを分ける発想を参考とする。
上記は公式機能の確認であり、人気順位や利用率を調査したものではない。製品の有料/無料プラン差をSunBWork仕様へそのまま移さない。

## SunBWorkへの推奨（以下すべて提案、未承認）
### 画面を2つの役割へ
- カレンダー左: 今日やる/期限が近い/超過の少数一覧、完了チェック/追加、件数。「TODOを開く」で専用ページ。月週日の見やすさを保つ。現在の全件表示の代替にする場合は利用者確認後。
- 専用TODOページ: 左に絞込と個人リスト、中央に検索/並べ替え付き一覧、右に選択TODOの詳細編集。モバイルは一覧→詳細。表示・リスト管理設定はこのページ内に置き、上段のメインメニューをむやみに増やさない。
- 現在の本人データと同じIDを使い、カレンダー/サイドバー/専用ページで編集・完了を同期。移動先だけ別のコピーを作らない。

### 最初に効く機能
1. 今日やる: 期限を変えず、その日に取り組むものを選ぶ。今日が終わっても未完了TODOは消さず元一覧へ残す。実際の締切と今日の選択を同じ日付フィールドにしない。
2. 重要スター: まず1段階の重要/通常。入力時の必須項目を増やさず後から付ける。期限超過の赤表示と重要スターの区別をつける。
3. 自動一覧: 今日やる/期限超過/今後7日/期限未定/すべて/完了。選択式検索と期限・重要・追加順の並べ替え。完了履歴も検索できる。
4. 個人リスト: 未整理（初期）、社内手続き、勉強・改善など本人が作成/名称変更/並べ替え。大まかな案件の共通分類とは別。分類なしで素早く追加できる。
5. 詳細ペイン: 名前/期限/今日やる/重要/リスト/色/メモ/チェック項目。チェック項目はまず1階層、「資料確認」「返信」「提出」等の完了2/3を表示。任意の深いタスクツリーを先に導入しない。
6. まとめて整理: 複数選択で期限変更・リスト移動・完了。削除は確認し、初期は取り消し/完了解除と本人境界/版競合を重視。
7. 個人設定: 左欄に出す対象（今日やる/直近等）、完了表示、初期一覧/並び、リスト管理。既存ページと同じレイアウト/戻る/編集削除配置を踏襲。

### 後段候補として保持
- 毎週/月末等の繰返し（編集対象が今回分か今後分か、完了履歴の保持が必要）。
- 指定時刻の本人リマインダー（初期OFF、本人が選択、まとめ通知/静かな時間帯を検討）。通知過多を避ける設定を先に設計する。
- TODO→MyJobの作業枠: 締切はそのまま残し、実施日/時間を別に選ぶ。作業枠保存だけでTODOを自動完了にせず、実績時間にも自動加点しない。旧工程で後段とした扱いを維持し、今回の調査から実装済みへ昇格させない。
- タグ「返事待ち」等、添付、定型テンプレート、保存した絞込。優先は利用者と相談。

## 推奨順と次の判断
第1段階: 専用ページ/3列・モバイル詳細、検索/自動一覧、今日やる/重要/個人リストと設定。小さなチェック項目も同じ段階で扱うか、初期ページの確認後に分けるかを設計で決める。
第2段階: 繰返し/通知/まとめ操作。
第3段階: TODO→MyJobの明示連携など。
本人専用とSuperAdmin試用を保って段階確認し、一般公開は別承認。次は利用者に推奨画面と機能優先を相談し、合意後にPLAN/MANAGER/PROMPTでDB/境界/既存データ保持/検証を具体化する。今回はソース/DB/本番変更なし。
