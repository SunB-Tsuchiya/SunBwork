# 年末調整フォーム 概要・フロー（総務向け）

更新: 2026-10-17 ／ 状態: **実装中**（受付・対象者・社員情報・権限管理まで作成済み。従業員の入力画面はこれから）。内容は打ち合わせで変わることがあります。
サンエー印刷・サン・ブレーン**両社**の従業員が、ポータル上で年末調整の控除申告を入力し、総務が回収・確認できる仕組みです。社員の基本情報は、別メニューの「社員情報」を使います（「社員情報ガイド」を参照）。

---

## 1. 全体の流れ

| 手順 | だれが | 内容 |
|---|---|---|
| ① 受付を作る | 総務 | 会社ごとに「令和8年分」の受付を作り、開始日・締切・案内文・会社側情報（税務署・支払者）を設定します。 |
| ② 対象者の確認 | 総務 | 社員・契約社員が自動で対象になります。個別の追加・除外もできます。 |
| ③ 案内する | 総務 | 既存の「お知らせ」と「リマインダー」で、開始や締切を案内します。 |
| ④ 入力する | 従業員（または総務が代理） | 対象になった人のユーザー用タブに「年末調整」が出ます。ステップに沿って入力し、途中保存もできます。 |
| ⑤ 提出する | 従業員（または総務が代理） | 内容を確認して提出します。締切前なら取り下げて直せます。 |
| ⑥ 確認する | 総務 | 内容を確認し、問題なければ完了。 |
| ⑦ 差し戻す | 総務 | 直してほしいステップとコメントを付けて返します。従業員は、そのステップだけ直して再提出します。 |

## 2. 従業員の入力ステップ

| ステップ | 内容 |
|---|---|
| 本人情報 | 氏名・住所・生年月日など。**「社員情報」から初期表示**され、確認・修正します。マイナンバーも社員情報から引き継ぎます。 |
| 本人の区分 | 障害者・ひとり親・寡婦・勤労学生などに該当するかを質問し、該当する人だけ詳細を入力します。 |
| 所得の見積り | 給与収入・給与所得などの見積額を入力します。 |
| 配偶者 | いない場合は飛ばせます。 |
| 扶養親族 | 人数分を追加します（最大20人）。 |
| 保険料控除 | 生命保険・地震保険・社会保険料・小規模企業共済等を入力します。 |
| 確認・提出 | 入力内容を一覧で確認して提出します。 |

- **前年の内容を読み込めます。** 扶養親族は「変更なし／変更あり／削除」を選び、保険は契約情報だけコピーして金額は今年分を入力します。（令和8年分は初年度のため、読み込めるのは来年からです。）
- **途中保存ができます。** 続きは、いつでも再開できます。

## 3. 総務ができること

| 機能 | 説明 |
|---|---|
| 受付の管理 | 会社ごとに受付を作成・編集します。サンエー印刷とサン・ブレーンは、会社のタブで切り分けて表示します。 |
| 回収状況 | 未入力・入力中・提出済み・差戻しの人数と、部署別の絞り込みを見られます。 |
| 内容の確認 | 提出された内容を開いて確認します。マイナンバーは伏せ字で表示されます。 |
| 差戻し | 直すステップを指定し、コメントを付けて返せます。 |
| 代理入力 | 端末のない従業員の分を、同じフォームで代わりに入力できます。 |
| 管理者メモ | 総務だけが見られるメモです。従業員には表示されません。 |
| 操作履歴 | 提出・差戻し・代理入力などを、だれがいつ行ったか記録します。 |
| 対象者の取り込み直し | 受付後に入社した人などを、ボタンで追加できます。 |

- これらの操作には、管理者から**「年末調整を管理する」権限**を与えられている必要があります。

## 4. 個人情報の扱い

- **本人のマイナンバーは「社員情報」で管理します。** 暗号化して保存し、年末調整を提出するときに、その時点の番号を申請にも暗号化してコピーします（7年間の保存義務があり、あとで社員情報が変わっても、過去の申告を変えないため）。
- 配偶者・扶養親族のマイナンバーは、年末調整の申請の中だけで持ちます。
- 画面では伏せ字（下4桁のみ）で表示し、全文は「表示する」ボタンを押したときだけ出ます。**全文表示は必ず記録**されます。
- 全文を見られるのは、管理者から**「マイナンバーを見る」権限**を与えられた人だけです。
- **試用中はダミーの番号だけを使います。**
- 従業員は、自分の申請だけ見られます。
- 代理入力のときは、「紙を受け取った」「本人に確認した」などを任意で記録できます。
- 退職などでユーザーを削除しても、年末調整の提出物と社員情報は消えません（7年間の保存義務のため）。

## 5. これまでに決めたこと（質問と答えの要約）

| # | 質問 | 決めたこと |
|---|---|---|
| 1 | 誰が入力するか | 従業員本人がログインして入力。端末のない人は総務が代理入力（約100名全員分のアカウントを発行）。 |
| 2 | サンプルの範囲 | 本人情報・配偶者・扶養親族・保険料控除。住宅ローン等は後から追加します。 |
| 3 | 入力の進め方 | ステップ形式。途中保存あり。前年の内容を読み込めます。 |
| 4 | 総務の確認機能 | 一覧・内容の確認・差戻し（コメント付き）。 |
| 5 | マイナンバー | 暗号化して保存、一覧は伏せ字、全文表示は記録。試用中はダミー番号。本人の番号は社員情報で管理（#22）。 |
| 6 | 本人情報の持ち方 | 「社員情報」を別に持ち、提出時にその年の内容を保存します。 |
| 7 | アカウントの発行 | 約100名全員分を、CSVで一括登録します。 |
| 8 | 受付期間 | 年度ごとに受付を作り、開始日・締切・案内文を設定します。**会社ごとに作ります（#30）。** |
| 9 | 対象者 | 社員と契約社員。派遣社員・業務委託は対象外（個別に追加・除外は可能）。 |
| 10 | 控除額の計算 | まずは計算せず、入力値の保存のみ。参考計算は後から。 |
| 11 | 保険料控除の範囲 | 国の様式どおり全体（生命・地震・社会保険料・小規模企業共済等）。 |
| 12 | 所得の見積り | 当面は従業員が入力。後から総務の事前入力に切り替え可能です。 |
| 13 | データの保存 | 項目ごとに保存し、提出時の内容は丸ごと控えも残します。 |
| 14 | 受付後の対象者の増減 | 作成時に固定し、「取り込み直し」ボタンで追加します。 |
| 15 | 本人の区分 | 国の様式どおり全部入れます（最初に該当を質問）。 |
| 16 | 扶養親族の区分の判定 | 従業員が選びます（基準は説明文で表示）。自動判定は後から。 |
| 17 | 代理入力の画面 | 本人入力と同じフォームを「代理モード」で使います。 |
| 18 | 代理入力時の本人確認 | 任意でチェック・メモを残せます。 |
| 19 | SmartHRの特徴 | 項目単位の差戻し・回収状況・管理者メモ・提出の取り下げ・操作履歴を採用。通知は既存のお知らせを活用。 |
| 20 | ユーザー情報と社員情報 | 別にします。社員情報は総務の特別な権限がある人だけが見られます（「社員情報ガイド」参照）。 |
| 21 | 両社の扱い | サンエー印刷の総務はサン・ブレーンの総務も兼ねるため、社員情報は両社を扱い、画面で会社ごとに切り分けます。 |
| 22 | マイナンバーの置き場所 | 本人の番号は社員情報に暗号化保存。年末調整の提出時に申請へコピーします。 |
| 30 | 年末調整の対象会社 | サンエー印刷・サン・ブレーン両方。受付は会社ごと。 |
| 31 | 従業員のタブ | 対象の受付がある人のユーザー用タブに「年末調整」を出します。サン・ブレーンの従業員も、対象のときだけ表示されます（それ以外は従来どおり）。 |

## 6. 今は作らないもの（後で実装を提案します）

| 項目 | 説明 |
|---|---|
| 差分リスト | 提出内容と社員情報の差を表示し、社員情報に反映します。（次の候補） |
| 受付の下書き/公開 | 公開前は総務だけが編集できます。 |
| ステップごとの注意書きの編集 | 総務が説明文を直せるようにします。 |
| CSV・一括ダウンロード | 税理士への受け渡し用です。 |
| 源泉徴収票の添付 | 中途入社者の前職分です。 |
| 控除額の参考計算 | 入力から控除額の目安を表示します。 |
| 扶養親族区分の自動判定 | 年齢・所得から区分を提案します。 |
| 住宅ローン・寄附金・従たる給与・特定親族特別控除 | 他の申告書を追加します。 |
| 控除証明書データの取り込み・XML出力・PDF出力 | 外部データ連携や出力形式は、税理士の受入仕様を確認してから進めます。 |
| 承認の記録・未提出者への催促通知 | 「確認済み」の記録と催促です。 |
| 入力ヘルプ | 試用してもらい、要望が出たら追加します。 |
| 受付の削除 | 提出物がない受付だけ削除できるようにします。 |

## 7. 総務にご確認いただきたいこと

- マイナンバーを実際に扱う時期と、全文を見られる担当者（権限を与える人）。
- 事務所の共有端末（PCやタブレット）の運用と、端末のない人の本人確認の方法。
- 税理士へ渡すデータの形式（XML・CSVなど）。
- 受付の時期（開始日・締切）の目安。会社ごとの違いがあるか。
- 両社それぞれの、所轄税務署・支払者の情報（法人番号・所在地）。
