## システム概要

### 校正の流れ

```
依頼者（Coordinator / User）
  └─ ジョブ詳細・進行表から「校正依頼」ボタンをクリック
        ↓
  校正コーディネーター（窓口）が受信
  └─ 校正カレンダー・作業量を確認しながら校正員を割り当て
        ↓
  校正員が作業
  ├─ PCあり → マイジョブとして自己登録・完了
  └─ PCなし → 校正コーディネーターが代わりに完了マーク
        ↓
  依頼者に完了通知（メールアイコンのバッジで確認）
```

### ロールと権限

| ロール | 校正依頼を送る | 校正カレンダー閲覧 | 校正状況閲覧 | 割り振り管理 |
|---|:---:|:---:|:---:|:---:|
| SuperAdmin / Admin | ✓ | ✓ | ✓ | ✓ |
| Leader（部署リーダー） | ✓ | ✓ | ✓ | ✓ |
| Coordinator（進行管理） | ✓ | ✓ | ✓ | — |
| ProofCoordinator（校正窓口） | ✓ | ✓ | ✓ | ✓ |
| Clerk | ✓ | ✓ | ✓ | — |
| User（オペレーター・校正員） | ✓ | ✓ | ✓ | — |

### 重要な注意点

- **校正締め切り**はジョブ全体の締め切りとは**別に設定**します。作成・校正・修正まで含めたジョブの締め切りより、校正締め切りを早めに設定してください
- 校正依頼は**ジョブ単位**で行います。ジョブのタイトルと案件IDが自動で引き継がれます
- 完了済みのジョブからは校正依頼を送れません（ボタンが非表示になります）
- 再校正が必要な場合は、マイジョブで**新しいジョブを作成**してから、改めて校正依頼してください

## 依頼する側のガイド

対象ロール: **Coordinator / User / Clerk** およびすべての上位ロール

### 校正依頼の送り方

校正依頼は以下の3箇所から送れます。状況に応じて使い分けてください。

---

#### A. マイジョブ詳細から依頼する

1. **マイジョブ**タブを開き、校正してほしいジョブの詳細画面へ進む
2. アクションボタンエリアにある「**校正依頼**」ボタン（ピンク色）をクリック
3. モーダルが開いたら以下を入力：
   - **タイトル** — ジョブタイトルが自動入力されます。必要に応じて編集してください
   - **校正締め切り** ★必須 — ジョブ全体の締め切りより早めに設定
   - **備考** — 校正上の注意点があれば記入（任意）
4. 「**校正依頼を送る**」をクリック

> ジョブのタイトルと案件IDは自動的に引き継がれます

---

#### B. 案件詳細ページから依頼する（User）

1. **案件確認**タブを開き、案件詳細へ進む
2. ページ下部の「校正依頼」セクションにある「**+ 校正依頼を送る**」ボタンをクリック
3. モーダルでタイトル・校正締め切り・備考を入力して送信

> この画面から送る場合、特定のジョブIDとは紐づかず案件IDのみ引き継がれます。
> 特定のジョブと紐づけたい場合は「A. マイジョブ詳細から依頼する」を使ってください

---

#### C. 進行管理表から依頼する（Coordinator）

1. 案件の進行管理表を開く
2. ツールバーにある「**校正依頼**」ボタン（ピンク色）をクリック
3. モーダルでタイトル・校正締め切り・備考を入力して送信

---

### 依頼後の確認方法

依頼を送信すると、校正コーディネーターに通知が届きます。依頼のステータスは以下の画面から確認できます。

**「校正状況」タブ**（各ロールのナビゲーションタブに追加されています）

| ステータス | 意味 |
|---|---|
| 依頼中 | 校正窓口が受理待ち |
| 割り当て済み | 校正員が決まった |
| 校正中 | 校正員が作業中 |
| 完了 | 校正完了。通知が届きます |

「**自分の依頼のみ**」ボタンを押すと、自分が送った依頼だけに絞り込めます。

---

### 校正依頼のキャンセル

- キャンセルできるのは**依頼中（pending）**のものだけです
- 校正窓口が受理した後はキャンセルできません。その場合は校正コーディネーターに直接連絡してください

---

### 校正カレンダーの見方

**「校正カレンダー」タブ**を開くと、現在進行中の校正依頼の締め切りが一覧できます。

- **灰色** — 依頼中（窓口受理待ち）
- **青** — 割り当て済み
- **橙** — 校正中
- **緑** — 完了

校正が混んでいる時期はカレンダーで確認してから、余裕を持った校正締め切りを設定しましょう。

## 校正管理者のガイド

対象ロール: **ProofCoordinator**（および SuperAdmin / Admin / 部署Leader）

### ナビゲーション

ヘッダーの「**校正管理**」リンクをクリックすると、校正管理エリアに入ります。
以下の5つのタブがあります。

```
[ 校正依頼受信 ] [ 割り振り管理 ] [ 校正カレンダー ] [ 校正員作業量 ] [ 案件校正履歴 ]
```

---

### タブ①：校正依頼受信

依頼者から送られてきた**未受理の校正依頼**が一覧表示されます。
タブ名の横に未受理件数のバッジが表示されます。

**操作手順：**

1. 一覧を確認し、**締め切り**と**依頼者**を確認する
2. 「**受理する**」ボタンをクリック → 自分の担当依頼として受け取る
3. 受理した依頼は「割り振り管理」タブに移動します

> 締め切りが赤字になっている場合は、期限が過ぎているか当日です。優先して対応してください

---

### タブ②：割り振り管理

受理済みで**進行中**（割り当て済み・校正中）の依頼が一覧表示されます。

**操作手順：**

**① 校正員を割り当てる**
1. 担当校正員の列にある「校正員を選択」セレクターをクリック
2. 一覧から校正員を選択（担当コードが「校正」のユーザーが表示されます）
3. 「**割り当て**」ボタンをクリック → 校正員にPCがある場合は通知が届きます

**② 作業開始をマークする**
- 「**開始**」ボタンをクリック → ステータスが「校正中」になります

**③ 完了をマークする**
- 「**完了**」ボタンをクリック → ステータスが「完了」になり、依頼者に通知が届きます
- PCを持たない校正員が作業を終えた場合は、**校正コーディネーターが代わりに完了ボタンを押す**ことで完了処理ができます

> 完了ボタンを押した時点で依頼者に通知が送られます。確実に校正が終わったことを確認してから押してください

---

### タブ③：校正カレンダー

進行中の全校正依頼を**締め切り日ベース**でカレンダー表示します。

- イベントには「タイトル（担当校正員名）」が表示されます
- 色の意味は依頼者側と同じ（灰：依頼中、青：割り当て済み、橙：校正中、緑：完了）
- 特定の日に依頼が集中していないか確認し、割り振りの参考にしてください

---

### タブ④：校正員作業量

月別に各校正員の**担当件数・進行中件数・完了件数**を確認できます。

**使い方：**
1. 対象月を「年月」セレクターで選択
2. 各校正員の件数を比較して、次の割り当て時の参考にする

> 特定の校正員に偏りが出ていないか定期的に確認し、均等な割り振りを心がけてください

---

### タブ⑤：案件校正履歴

全案件の校正依頼履歴を時系列で確認できます。

- **検索ボックス**でタイトルや案件名を入力して絞り込みできます
- 完了済みの依頼も含めて一覧表示されます
- 「いつ・誰が・誰に・どのジョブを依頼したか」を一覧で把握できます

---

### 校正員候補について

割り振り管理の「校正員を選択」セレクターには、**担当（assignment）コードが「校正（kousei）」のユーザー**が表示されます。

校正員を追加・変更したい場合は、Admin画面の「ユーザー管理」から対象ユーザーの担当を「校正」に変更してください。また「校正チーム」への所属登録も合わせて行うと、管理が一元化できます。

---

### 日常の運用フロー（推奨）

```
朝の確認
  └─ 「校正依頼受信」タブを開き、未受理の依頼がないか確認
        ↓
受理・割り振り
  └─ カレンダー・作業量タブで混み具合を確認してから校正員を決める
        ↓
作業中
  └─ 「開始」ボタンで校正中ステータスに変更
        ↓
完了確認
  └─ 校正員から「終わった」の報告を受けたら「完了」ボタンを押す
     （PCなし校正員の場合は特に重要）
```

## 全員が閲覧できる画面

### 校正カレンダー

各ロールのナビゲーションタブに「**校正カレンダー**」があります。

- 進行中の校正依頼の締め切りを月別カレンダーで確認できます
- 担当校正員名も表示されるため「自分のジョブを誰が校正しているか」がわかります
- 編集・操作はできません（閲覧専用）

### 校正状況

各ロールのナビゲーションタブに「**校正状況**」があります。

- 全員の校正依頼が一覧で確認できます
- 「自分の依頼のみ」ボタンで絞り込みできます
- ステータス・担当校正員・締め切りが一目でわかります

## よくある質問

**Q. 校正依頼を送ったが、「校正状況」に表示されない**
A. ページを再読み込みしてください。それでも表示されない場合は校正コーディネーターに確認してください。

**Q. 校正締め切りを間違えて設定してしまった**
A. 依頼中（pending）のうちに一度キャンセルして、正しい締め切りで再依頼してください。受理後は校正コーディネーターに直接連絡して変更を依頼してください。

**Q. 同じジョブに対して2回校正が必要になった**
A. マイジョブで**新しいジョブを作成**してから、そのジョブに対して校正依頼を送ってください。同じジョブへの重複した依頼はできません。

**Q. 校正員が変わった場合はどうすればよいか**
A. 校正コーディネーターが「割り振り管理」タブで校正員を変更できます（割り当て後でも変更可能）。

**Q. PCを持たない校正員が作業したことをどう記録するか**
A. 校正コーディネーターが「割り振り管理」タブの「完了」ボタンを押すことで記録できます。依頼者にも通知が届きます。

**Q. 「校正依頼」ボタンが表示されない**
A. 以下を確認してください：
① ジョブまたは案件が「完了」になっていないか（完了済みはボタン非表示）
② 正しいページを開いているか（マイジョブ詳細 / 案件詳細 / 進行管理表）
