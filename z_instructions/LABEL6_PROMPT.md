## このフェーズで実装するもの

1. `label_area_masters` テーブル + Master UI（社内便マスタの右）
2. Excel エリア解析（～小計行を2パスで検出してエリア名を付与）
3. データ照会ビュー（FileMaker 風の学校×部数一覧）
4. 部数集計モーダル（エリア別×シンボル別集計）

## 実装優先順

Phase 6-1 → 6-2 → 6-3 の順で実装し、各フェーズ完了後に `npm run build` と動作確認。

## 注意点

- エリア名は Excel の「～小計」行から抽出（例: 「本部小計」→ '本部'）
- `parseSchoolRows` に2パス処理を追加して `area` フィールドを付与
- データと部数は同値（V2 ではマスタ調整なし）→ 「部数」1列のみ
- 赤セル = qty === 0 の学校行
- エリア並び順 = エリアマスタの sort_order 順
- さくら CSRF は `meta[name="csrf-token"]` から取得
