# MGinbon 値一覧マスター 再開プロンプト1

`MGINBON_VALUE_MASTER_PLAN1.md` と `MGINBON_VALUE_MASTER_MANAGER1.md` を読み、利用者承認後にFileMaker型値一覧マスターを実装する。

## 現在地

- 出稿表は利用者確認済み。
- 単価マスター設計後、FileMaker値一覧画像の提供により値一覧マスターを先行する方針になった。
- 13種類の一覧種別はコードで固定し、年度別の値を追加・編集・無効化・並べ替え可能にする。
- 担当者値は本体ユーザー／外注先へ任意リンク可能にするが、名前一致で自動確定しない。
- 既存の媒体・教科等の正規テーブルは維持し、値一覧は入力候補レイヤーとして接続する。
- MGinbonテストは一時SQLiteを使用する。
- Sakuraへはデプロイしない。
